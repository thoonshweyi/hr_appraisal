Option 1: Cast data to JSONB in the query
SELECT *
FROM notifications
WHERE (data::jsonb)->>'specific_form_id' = '42914';

Or for an integer comparison:

SELECT *
FROM notifications
WHERE ((data::jsonb)->>'specific_form_id')::int = 42914;
Option 2: Change the column type permanently (recommended)

If all values in data are valid JSON:

ALTER TABLE notifications
ALTER COLUMN data TYPE jsonb
USING data::jsonb;

Then your original query will work:

SELECT *
FROM notifications
WHERE data->>'specific_form_id' = '42914';

To verify the column type, run:

SELECT column_name, data_type
FROM information_schema.columns
WHERE table_name = 'notifications'
  AND column_name = 'data';

If it returns text, use the cast (data::jsonb) or convert the column to jsonb.



SELECT *
FROM public.notifications
WHERE data::jsonb ->> 'appraisal_cycle_id' <> '5'
  AND read_at IS NULL
ORDER BY id DESC;

    af.*,
    u.employee_id,
    e.employee_code,
    e.position_level_id
FROM public.appraisal_forms af
JOIN public.users u
    ON af.assessor_user_id = u.id
JOIN public.employees e
    ON u.employee_id = e.employee_code
WHERE af.appraisal_cycle_id = 4
  AND af.deleted_at IS NULL
  AND af.delete_by IS NULL

      af.modify_user_id = 79
